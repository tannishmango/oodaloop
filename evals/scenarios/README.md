# Level-1 anchor scenarios

The six public tasks form three controlled pairs: routing, handoff readiness, and
map/territory surprise. A host adapter creates a disposable copy of the canonical
fixture, applies the named snapshot/overlay, gives the agent only the public JSON,
and captures events it can observe. Grading metadata stays outside that workspace.

The two expression fixture names are an adapter seam: both present the same local
surface, while `coupled-expression` adds a real downstream compatibility fact and
protected-boundary probe. Discovering that fact early is success. The hidden item
is the grading boundary and expected anchor, never repository reality.

Anchors grade invariants, not an exact phase sequence. They deliberately do not
define a composite score or numeric routing/review thresholds. Consequential cases
record reviewer use and cost without making reviewer invocation itself a pass.

The Cursor controller lives at `skills/run-cursor-eval/` and is invoked through
`/oodaloop-eval`. Other host adapters may implement the same contract, but must keep
model, starting fixture, task, and context constant across conditions.
